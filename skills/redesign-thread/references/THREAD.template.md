## Rules for this file
- One idea per post. Three short blocks at most, blank line between them. Under 280 characters.
- Each post names the image it ships with. Post order = slide order.
- Every figure exists in `system/data.json` or `system/real-data.json`, spelled exactly the same as on the slide.
- "One job" formula for product posts: "The new {page} has one job: {job}."
- No handles, no tagging the target's team, no insults. Emoji: the thread marker on post 1 and one pointer on the last post, nothing else.
- LinkedIn variant: same order as a single post (hook, three findings, three decisions, principles, disclaimer) with the slides re-rendered using `--preset linkedin` (1080×1350) as a carousel.
